# Representative result fixtures

These inert, hand-reviewed fixtures demonstrate result shape without preserving
machine-specific timings, paths, usernames, or large generated outputs. They are
not engine quality evidence; authoritative measurements remain in ignored,
immutable per-run directories and summarized reports.
