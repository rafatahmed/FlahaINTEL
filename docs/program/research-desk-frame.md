# Research desk frame (Stage D)

## Position in FlahaINTEL

```text
EYES          Sources · Submit · Markets harvest
MUSCLES       Jobs · packs · market store · analytics · [4R-A index]
BACKBONE      Artifacts · evidence · audit
BRAIN         Review · feed policies · [4R desk browse]
FEEDS         4I-B handoff → SOIL | CALC | FAST (separate)
```

Research desk is **not** a fourth sister product. It is how PA **finds and assembles** governed knowledge already in INTEL.

## Two gates

| Gate | Name | Outcome |
|------|------|---------|
| **4R-A** | Topic index | Facet browse over approved content |
| **4R-B** | Research collection | Named set for scientific writing / report |

Full charter: `docs/program/gates/gate-4r-a-research-topic-index.md`.

## Do not confuse with

| System | Role |
|--------|------|
| **Markets analytics** | Price time series, multi-year curves, histogram of **prices** |
| **Knowledge lanes** | Create/review packs per SOIL/CALC/FAST |
| **4I-B handoff** | Export envelope **out** to product process |
| **FKP** | Frozen-thin methodology / authority docs (not INTEL ops index) |

## Recommended build order

1. Accept **4R-A** frame  
2. Implement **4R-A.1** MVP (materialized index + API + Research tab)  
3. Operate: approve packs → rebuild → use filters  
4. Charter **4R-B** when writers need collections  

## Parallel track (optional)

**Historical market fill** remains a **Markets operate** track (stronger multi-year price curves). It does not replace 4R-A; it feeds MARKET_CONTEXT packs and Markets analytics only.
